How to use the Upstream Prototype

This page explains workflow, features, roles, and how the two operational pages connect.

Forecast & Coordination Operations Matrix Tutorial

1) Forecast & Coordination page

  • Select a procedure type i.
  • Set severity index type + severity score i.
  • Add/adjust blocker category and planned departure time.
  • Use Add patient & Sync to create a new patient and occupy a bed.

2) Operations Matrix page

  • Switch between Global view and per-service view.
  • Click a bed to inspect patient details and threshold risk.
  • Use Modify patient in Forecast page to jump to editing workflow.
  • Discharge action frees bed immediately; assigning a waiting patient occupies it.

3) Roles and update workflow

  • Planner mode: full input and coordination controls.
  • Nurse mode: lighter view for quick operational reading.
  • When editing a patient from matrix, use Confirm update or Decline update.
  • Recompute LOS on update is optional.

4) Demo sequence (recommended)

  1. Add two patients in Forecast page.
  2. Open Operations Matrix and show both occupied beds.
  3. Filter by one service.
  4. Modify one patient from matrix and confirm update without LOS recompute.
  5. Discharge one patient and show bed becomes free in real time.
