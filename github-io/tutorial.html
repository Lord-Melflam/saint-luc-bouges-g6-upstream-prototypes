How to use the Upstream Prototype

Forecast & Coordination Operations Matrix Tutorial

1) End-to-end workflow

  1. Create patient in Forecast & Coordination.
  2. System generates patient ID automatically and computes LOS/threshold risk.
  3. Bed assignment tries preferred bed type in selected service.
  4. If impossible, patient is queued with reason + timestamp.
  5. Open Operations Matrix to inspect beds, queue, and reassign/discharge.
  6. Edit from matrix if needed (confirm/decline update, optional LOS recompute).

2) Forecast inputs explained

  • Procedure type: drives default service + specialty mapping.
  • Severity index type: charlson or elixhauser framing.
  • Severity score: 0–15 severity intensity.
  • Gender: used in LOS computation.
  • Primary blocker: medical/admin/transport/family/logistics/none.
  • Bed type + policy: - strict: queue if preferred bed unavailable, - flexible: assign alternative type if possible.
  • IDAG / DMG: optional grouping placeholders from stakeholder notes.

3) Outputs explained

Example forecast output:

patient_id: P-LIVE-0007
predicted_los_days: 5
severity_index: charlson=4
gender: female
expected_discharge_date: 2026-05-12
planned_departure_time: 11:00
assigned_bed: none
threshold_risk_status: info
billing_loss_risk: no
data_quality_warnings: Preferred type unavailable in selected service

Meaning:

  • assigned_bed: none means patient is queued, not lost.
  • threshold_risk_status indicates distance to discharge billing cutoff.
  • data_quality_warnings indicates operational assignment constraints.

Nurse script and SMS panels are operational communication templates derived from same patient state.

4) Operations Matrix usage

  • Use Global view to see all services; use service filter for local focus.
  • Click a bed tile to inspect patient + risk details.
  • For occupied bed: - discharge (frees bed), - modify patient (opens forecast edit mode).
  • For free bed: - assign a queued/waiting patient directly to this bed.

5) Role modes

  • Planner: full data-entry and coordination controls.
  • Nurse: a read-first board with active patients, per-unit filters, and the selected patient's monitoring snapshot.

6) Nurse station

  • Starts with active patients instead of an empty screen.
  • Use Unit filter for per-service monitoring or All units for a global list.
  • Select any row to refresh the nurse script, LOS, risk, and next action output.
  • Useful at login for a shift handover: who is active, who is waiting, and who is at risk.

7) Simulation presets

Use preset buttons on Forecast page to inject realistic stress scenarios quickly:

  • Late transport
  • Unresolved blocker
  • Late medical validation
  • Occupancy spike
  • Missing critical data

Recommended presentation flow: baseline patient -> trigger preset -> observe queue/occupancy/risk changes in matrix.

8) Monitoring panel

  • Shows current occupancy and forecast occupancy horizon with axis labels and point values.
  • Supports service-specific or global perspective.
  • Forecast horizon can be longer than current LOS, and the chart rescales automatically.
  • Updates whenever patient creation/update/discharge changes state.
